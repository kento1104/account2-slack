Filter Script

The script receives a user object (the raw Slack user JSON) and must return true to send a message to that user, or false to skip them. The variables score and threshold may be defined in the script; their values are recorded for each sent user and displayed in the Users table below. If left empty, every user passes the filter.

Message Template

Use {path.to.field} to substitute values from the current user's JSON (e.g. {profile.display_name}).
Use {AI_answer} to insert the text generated from the AI prompt below. If {AI_answer} is present, the AI is called per user and its result is substituted; otherwise the template is sent as a static message with user-field substitution only.
